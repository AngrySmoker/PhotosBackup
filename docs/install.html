Manual install

  1. AirDrop the IPA to the iPhone and save it in Files.
  2. Turn on LocalDevVPN.
  3. In SideStore, tap +, choose PhotosBackup.ipa, and install it.
  4. If asked whether to retain app extensions, keep Photos Backup Connect.
